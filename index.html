how it works

two data streams,
one little koala

01
intercept API calls
A lightweight SDK wrapper catches every outbound LLM call and counts tokens before returning the response.
02
measure device load
psutil polls CPU and memory every 60s, estimates wattage, multiplies by live grid carbon intensity.
03
merge into one number
Both streams combine into a rolling gCO₂ total, stored locally in SQLite. Nothing leaves your machine.
04
Watts reacts
The desktop character updates its mood state, sends nudges, and roasts you when you deserve it.

installation

Install carb-0n via pip. Python 3.9+ required.

# install
pip install carb-0n

# launch Watts on your desktop
carbon0 start

wrapping LLM calls

carb-0n works by wrapping your existing API calls. Add one import and one wrapper function — that's it.

# works with OpenAI, Anthropic, Google
from carbon0 import track

response = track(your_llm_call(...))

configuration

carb-0n auto-detects your region for grid intensity. You can override in ~/.carbon0/config.toml.

[region]
zone = "IN-NO" # India North

[watts]
nudge_interval = 30 # minutes
roast_mode = true
daily_story = true

watts mood states

Watts transitions between four states based on your rolling 1-hour CO₂ total.

happy < 5g CO₂/hr · efficient session
stressed 5–15g CO₂/hr · building up
overload > 15g CO₂/hr · watts is judging you
sleeping idle detected · emissions paused

privacy

All data is stored locally in ~/.carbon0/data.db (SQLite). carb-0n makes exactly one external request: fetching live grid intensity from Electricity Maps. No prompt content is ever stored or transmitted.

about

why carb-0n?

Every time you ask an LLM a question, it burns energy in a data center somewhere. Most developers have zero visibility into this and that's a problem, because LLM usage is growing fast.

carb-0n was built to make that cost tangible. Not to make you feel guilty, but to make you a more intentional developer. Tighter prompts. Lighter models when they'll do. Awareness that compounds over time.

Watts is your companion in that. He's not preachy. He's just honest.
